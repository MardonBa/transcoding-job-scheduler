# Transcoding-Job-Scheduler

## Documentation structure

All docs can be found at `docs/`. `IMPLEMENTATION_NOTES.md` contain my sketch of frontend, backend, user flow, tech stack, etc should be.

Diagrams were then generated by Claude and put at `docs/diagrams/`. Contains UML diagrams for architecture, user flows, etc.
Contracts for the build: `docs/API.md` (routes, payloads, errors), `docs/SSE.md` (live events), `docs/OAUTH.md` (login and sessions), `docs/NGINX.md` (reverse proxy and presigned URLs).
Learning resources for the Go backend, ordered by build phase: `docs/GO_LEARNING.md`.
